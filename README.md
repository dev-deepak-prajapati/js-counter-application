# 🔢 JavaScript Counter Application

A simple, lightweight, and interactive **Counter Application** built using **Vanilla JavaScript**, **HTML5**, and **CSS3**. Perfect for beginners learning DOM manipulation and event handling in JavaScript.

---

## ✨ Features

- **Increment**: Increase the counter value instantly with a click.
- **Decrement**: Decrease the counter value.
- **Reset**: Quickly reset the counter back to zero.
- **Clean UI**: Modern, minimalist styling with responsive layout design.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)

---

## 📁 Project Structure

```text
js-counter-application/
│
├── index.html       # Main HTML layout structure
├── style.css        # Application styles and design
└── script.js        # Counter logic, DOM manipulation, and event listeners
```


## ⚙️ How to Setup Locally
To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dev-deepak-prajapati/js-counter-application.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd js-counter-application
   ```

3. **Open the project:**
   Simply double-click `index.html` or run it using an extension like **Live Server** in VS Code.
